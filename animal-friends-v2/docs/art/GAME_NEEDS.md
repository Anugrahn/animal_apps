> `need-animals-1/2`, `need-food-1/2`, `need-things-1…4`, `need-vehicles`,
> `need-nature-1/2` and `need-places` in Part B below.

**How to read this file**

- **Part A** goes island → game → sub-game (each level) and says what that sub-game needs, like *"ABC Island · Letters · S and A — needs: sun, apple"*. Things already painted are left out.
- **Part B** collects all of those pictures, without repeats, into ready-to-paste **sheet prompts** for ChatGPT. Make Part B; Part A shows where each picture will appear.
- Use the **style lock** from `ASSET_PROMPTS.md` Part 1 at the start of each ChatGPT chat, and save sheets into `interface/assets/sheets/`.
