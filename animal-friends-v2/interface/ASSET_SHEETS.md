# Animal Friends — pictures still drawn as emoji (2026-10)

For making the remaining game art in ChatGPT, the same way as the art already in
`art/pic/`. Every picture below still shows as an emoji in a game today.
Made from the content on 2026-10-13 (after the curriculum fixes: gift, truck,
chair, breakfast). Level icons (only in the grown-up area) are left out.

**202 pictures in 16 sheets.** The table at the end says where each one goes;
Claude uses it to cut the sheets and put each picture in the app.

## How to make them

1. Start a new ChatGPT chat. Attach `new_interface/games.png` and an animal
   sheet from `assets/icon_characters/`, so the style matches the app.
2. Paste the **style lock** below once.
3. Paste one sheet prompt at a time. Save each picture into
   `interface/assets/sheets/` with the file name shown (for example
   `need2-animals-1.png`).
4. Check each sheet: transparent background (Preview → View → Show Image
   Background: no white, no checkerboard), the right number of objects, in
   order. If one is wrong, ask ChatGPT to redo that sheet. A missing or extra
   object is fine: just say which.
5. When some sheets are saved, tell Claude: it cuts them into single pictures,
   puts them in the app and checks every game.

### Style lock (paste first)

```
You are making game art for "Animal Friends", a learning app for children aged 2 to 8.
Match the attached images exactly: soft rounded 3D clay / vinyl-toy style, matte with
gentle highlights, bright friendly colours, thick chunky shapes, no hard outlines,
warm soft light from the top left.

Every image in this chat is a SHEET of separate objects:
- Transparent background (PNG). Not white, not a checkerboard.
- Objects arranged in a neat grid, in the order I list them, left to right, top to bottom.
- Lots of empty space between objects (at least 60 px). No object touches another.
- Each object complete, centred in its own cell, nothing cut off.
- No text, no letters or numbers unless I ask for them, no labels, no watermark.
- No ground shadow and no background scenery under the objects.
- All objects on one sheet roughly the same size and seen from the same slight
  front-top angle.
- Landscape 1536 x 1024.
Reply "Ready".
```
